Blockmap かんたん設定

Realm の地図サイトを 4 つの手順で立てます。このページはパスワードやトークンを求めず、どこにも送信しません。

必要なもの:Realm のオーナーの Microsoft アカウント、GitHub アカウント、Cloudflare アカウント(どれも無料)。

  1. 1リポジトリを作る

    下のボタンを開いて、リポジトリを作ります。公開範囲は Public のままにします。Include all branches にはチェックを入れません。

    自動更新は GitHub Actions で動きます。Actions を無制限に無料で使えるのは公開リポジトリだけです(非公開は月 2,000 分まで。Blockmap は月 4,000 分ほど使います)。

    公開されるのは、プログラムと暗号化したデータだけです。ゲーマータグや座標は表に出ず、サイトに入れるのは Realm のメンバーだけです。鍵やログイン情報は公開されません。

    GitHub でリポジトリを作る

  2. 2Cloudflare のトークンを作る

    下のボタンを開き、内容を確認して Continue to summary → Create Token を押します。表示されたトークンをコピーします(一度しか表示されません)。

    トークンを作る

    このようになっていれば OK です(足りなければ追加します):

    • Permissions:
      • Account · Workers Scripts · Edit
      • Account · D1 · Edit
      • Account · Account Settings · Read
    • Account Resources: Include · All accounts (または自分のアカウント)
    • Client IP Address Filtering: 空のまま
    • TTL: 空のまま(期限なし。期限を付けると、その日から更新が止まります)

  3. 3Secret を 2 つ登録する

    下のボタンを開いて、次の 2 つを 1 つずつ登録します(Name と Secret を入れて Add secret)。

    「New repository secret」を開く

    NameSecret
    REALMS_CACHE_KEY
    CLOUDFLARE_API_TOKEN 手順 2 のトークン

    ランダムな文字列は、このブラウザで作ったもので、どこにも保存されません。読み直すと作り直されるので、表示中のものを登録してください。覚えておく必要はありません。

    必要な場合だけ
    REALM_NAME
    Variable    		 Realm を 2 つ以上持っている場合:地図にする Realm の名前。マイクラの「Realms」の一覧に出ている名前です(ワールド名ではありません)。Variables タブに登録します。
    CLOUDFLARE_ACCOUNT_ID
    Secret    		 Cloudflare のアカウントを 2 つ以上持っている場合:使うアカウントの ID(Workers & Pages の右側に表示されます)。
    LANGUAGE
    Variable    		 GitHub Actions のメッセージを英語にする場合:en(なければ日本語)。
    TIMEZONE
    Variable    		 日本以外のタイムゾーンを使う場合(例:America/New_York)。

  4. 4Realms にログインする(続けて地図ができます)

    1. 下のボタンを開きます。初回は I understand my workflows, go ahead and enable them を押します。
    2. 右の Run workflow → What to do を Sign in to Realms にして → 緑の Run workflow を押します。
    3. このページに戻ります。コードの場所と、地図の進み具合がここに出ます。

    「Map site」を開く

    ログイン後、Microsoft の画面に「Minecraft for Nintendo Switch」と出ますが、正常です。Realms には公開された入り口がないため、Switch 版マイクラと同じ方法でログインしています。使えるのは Xbox Live と Realms だけで(メール・ファイル・支払いには届きません)、パスワードは一切扱いません。
