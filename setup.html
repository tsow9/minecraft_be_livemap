Chizuya セットアップ

Realm のメンバーだけが見られる地図サイトを作ります。できたサイトのリンクを仲間に送れば、みんながブラウザで地図を見られます。

所要時間は 15 分ほどです。

必要なもの(すべて無料):Realm のオーナーの Microsoft アカウント、GitHub アカウント、Cloudflare アカウント

うまくいかないときは、このページの下のトラブルシューティングを参照してください。

  1. 1リポジトリを作る

    下のボタンを押して、リポジトリを作ります。公開範囲は Public のままにします。
    Include all branches にはチェックを入れません。

    自動更新は GitHub Actions で動きます。Actions を無制限に無料で使えるのは、公開リポジトリだけです。非公開は月 2,000 分までで、Chizuya は月 4,000 分ほど使います。

    公開されるのは、プログラムと暗号化したデータだけです。ゲーマータグや座標は表に出ず、サイトに入れるのは Realm のメンバーだけです。

    リポジトリの名前(例:chizuya)が、サイトのアドレスの最初の部分になります。Realm を 2 つ以上地図にするときは、Realm ごとに別の名前でリポジトリを作ります。

    GitHub でリポジトリを作る

    リポジトリの画面を閉じてしまった場合は、リンクの探し方を見てください。

  2. 2Cloudflare のトークンを作る

    1. 下のボタンを押します。必要な権限は入力済みです。
    2. いちばん下の Continue to summary を押し、続けて Create Token を押します。
    3. 表示されたトークンをコピーします。トークンは一度しか表示されないので、そのまま手順 3 に進みます。

    トークンを作る

  3. 3トークンをリポジトリに登録する

    1. 下のボタンを押します。GitHub の「New secret」の画面が開きます。
    2. 「Secret」に、手順 2 でコピーしたトークンを貼ります。
    3. 「Name」に貼ります: CLOUDFLARE_API_TOKEN
    4. 「Add secret」を押します。

    トークンが登録されたことの確認には、数分かかる場合があります。

    「New secret」の画面を開く

  4. 4Realms にログインする

    トークンを登録すると、自動的にログインの準備が始まり、入力するコードが下に表示されます。このコードで Microsoft にログインすると、少し経ってサイトの構築が始まります。

    ログインの確認には、数分かかる場合があります。

    ログイン後、Microsoft の画面に「Minecraft for Nintendo Switch」と表示されますが、正常です。

  5. 5仲間にリンクを送る

    サイトを開いて Microsoft でログインします。あなたが管理者です。
    下のアドレスを Realm のメンバーに送ります。

    メンバーは、リンクを開いて、マイクラで使っている Microsoft アカウントでログインするだけです。

トラブルシューティング

リポジトリの画面を閉じてしまった(手順 1 のリンク)
  1. GitHub の自分のリポジトリの一覧を開きます(ログインを求められたら、ログインします)。
  2. 手順 1 で作ったもの(例:yourname/chizuya)を押します。
  3. ブラウザの上に出ているアドレスをコピーして、手順 1 の欄に貼ります。
トークンをコピーする前に画面を閉じてしまった(手順 2)

トークンは一度しか表示されないので、作り直します。同じ名前のままで問題ありません。

  1. Cloudflare の API Tokens の画面を開き、不要なトークンを「…」から削除します。
  2. 手順 2 のボタンからもう一度作り、手順 3 に進みます。

消し忘れても動きに影響はありませんが、使わないトークンは消しておくほうが安全です。

Cloudflare のトークンの設定が合っているか確かめたい

手順 2 のボタンから開くと、次の設定が最初から入っています。違っていたら、そのボタンからトークンを作り直して、手順 3 で貼り直します。

  • Permissions(権限):Account・Workers Scripts・Edit / Account・D1・Edit / Account・Account Settings・Read(この 3 つだけ)
  • Account Resources:Include・All accounts(または自分のアカウント)
  • Client IP Address Filtering と TTL:空のまま(期限を入れると、その日に地図の更新が止まります)
手順 4 にコードが出てこない
  • 手順 1 の欄に、自分が作ったリポジトリのリンクが入っているか確かめます。
  • 手順 3 のボタンをもう一度押し、Repository secrets に CLOUDFLARE_API_TOKEN があるか確かめます(つづりが一字でも違うと動きません。Variables や Environment secrets ではありません)。
コードが出る前に「ログインできませんでした」と出た

トークンで、Chizuya に必要な操作ができません(作るときに設定が変わった、または途中までしかコピーできていない、など)。

  1. 手順 2 のボタンから、画面の内容を変えずにトークンを作り直します。
  2. 手順 3 のボタンを押し、CLOUDFLARE_API_TOKEN の横の鉛筆マークを押して、新しいトークンを貼り直します。
  3. このページを開いていれば、すぐに自動でログインがやり直され、手順 4 にコードが出ます(開いていないときは 10 分ほどのうちに)。
コードを入れた後に「ログインできませんでした」と出た
  • コードの有効期限は約 15 分です(手順 4 に残り時間が出ます)。このページを開いたまま過ぎた場合は、1〜2 分で手順 4 に新しいコードが出ます。別の日に続きをするときも、このページを開けば新しいコードが出ます。
  • Realm のオーナーの Microsoft アカウントでログインします。
「地図を作れませんでした」と出た
  • 「記録を見る」を開き、赤いメッセージを探します。メッセージごとの意味と直し方は、説明書の表にあります。
  • 赤いメッセージに Cloudflare のこと(アカウント・鍵・公開先のアドレス・公開)が出ている場合は、トークンに必要な権限が足りません。トークンの作り直し方と同じ手順で作り直して貼り直し、次の地図の更新(1 時間以内)を待ちます。
  • Realm を 2 つ以上持っている場合は、手順 4 で選びます。あとから変えるときは、Variables に REALM_NAME(Realm の名前)を追加して、地図を更新します。
Microsoft の画面に「Minecraft for Nintendo Switch」と出た
  • 正常です。Chizuya は、Switch 版のマイクラと同じ方法で Realms にログインします(理由)。
仲間がサイトに入れない
  • 入れるのは Realm のメンバーだけです。マイクラで使っている Microsoft アカウントでログインしてもらいます。
このページの表示が変わらない
  • ページを再読み込みします。進み具合は、GitHub の Map site でも見られます。
