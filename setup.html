Blockmap かんたん設定

Realm の地図サイトを 5 つの手順で立てます。このページはパスワードやトークンを求めず、どこにも送信しません。チェックはこのブラウザにだけ保存されます。

必要なもの:Realm のオーナーの Microsoft アカウント、GitHub アカウント、Cloudflare アカウント(どれも無料)。

  1. 1リポジトリを作る

    1. 下のボタンを開き、Public のまま、Include all branches にはチェックを入れずに作成します。

    GitHub でリポジトリを作る

  2. 2Cloudflare を準備する

    1. Workers & Pages を開きます。サブドメインを聞かれたら決めて、ここにも入れます:

      Workers & Pages を開く

    2. API トークンを作ります(権限は入力済みです:Workers Scripts: Edit、D1: Edit、Account Settings: Read。足りなければ追加してください)。表示されたトークンを控えます(一度しか表示されません)。

      トークンを作る

    3. Workers & Pages の画面(右側)に出ている Account ID を控えます。

  3. 3Secrets と Variables を登録する

    次の 4 つを Secret として 1 つずつ登録します(Name と値を入れて Add secret)。

    「New repository secret」を開く

    REALMS_CACHE_KEY
    SHARE_PASSPHRASE
    CLOUDFLARE_API_TOKEN 手順 2 のトークン
    CLOUDFLARE_ACCOUNT_ID 手順 2 の Account ID

    2 つのランダムな文字列は、このブラウザで今作ったもので、どこにも保存されません。ページを読み直すと作り直されるので、表示中のものを登録してください。

    続けて、次を Variable として登録します(Variables タブ)。

    「New repository variable」を開く

    LANGUAGE
    TIMEZONE
    REALM_NAME Realm を 2 つ以上持っている場合だけ、使う Realm の名前

  4. 4Realms にログインする

    1. 下のワークフローを開きます(初回は Actions タブでワークフローを有効にします)。
    2. 「Run workflow」→ What to do で Sign in to Realms を選び → Run workflow。
    3. 実行中の login を開き、表示されたコードを microsoft.com/link に入れて、Realm のオーナーのアカウントでログインします。

    「Map site」を開く

  5. 5地図を作る

    1. 同じ画面で「Run workflow」→ Update map を実行します。数分かかります。
    2. 終わったら、サイトを開いて Microsoft でログインします。あなたが管理者です。

    サイトを開く

    あとは、住所を Realm のメンバーに送るだけです(管理者メニュー → サイトのURLをコピー)。
