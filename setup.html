Blockmap セットアップ

Realm のメンバーだけが見られる地図サイトを作ります。できたサイトのリンクを仲間に送れば、みんながブラウザで地図を見られます。

所要時間は 15 分ほどです。

必要なもの(すべて無料):Realm のオーナーの Microsoft アカウント、GitHub アカウント、Cloudflare アカウント

うまくいかないときは、このページの下のトラブルシューティングを参照してください。

  1. 1リポジトリを作る

    下のボタンを開いて、リポジトリを作ります。公開範囲は Public のままにします。
    Include all branches にはチェックを入れません。

    自動更新は GitHub Actions で動きます。Actions を無制限に無料で使えるのは、公開リポジトリだけです。非公開は月 2,000 分までで、Blockmap は月 4,000 分ほど使います。

    公開されるのは、プログラムと暗号化したデータだけです。ゲーマータグや座標は表に出ず、サイトに入れるのは Realm のメンバーだけです。

    リポジトリの名前(例:blockmap)が、サイトのアドレスの最初の部分になります。Realm を 2 つ以上地図にするときは、Realm ごとに別の名前でリポジトリを作ります。

    GitHub でリポジトリを作る

  2. 2Cloudflare のトークンを作る

    1. 下のボタンを開きます。必要な権限は入力済みです。
    2. いちばん下の Continue to summary を押し、続けて Create Token を押します。
    3. 表示されたトークンをコピーします。トークンは一度しか表示されないので、そのまま手順 3 に進みます。

    トークンを作る

  3. 3トークンをリポジトリに登録する

    1. 下のボタンを開きます。GitHub の「New secret」の画面が開きます。
    2. 「Secret」に、手順 2 でコピーしたトークンを貼ります。
    3. 「Name」に貼ります: CLOUDFLARE_API_TOKEN
    4. 「Add secret」を押します。

    「New repository secret」を開く

    英語で使う場合や、日本以外のタイムゾーンの場合は、下のボタンから次を追加します(Secrets ではなく Variables です)。Realm を 2 つ以上持っている場合は、手順 4 で選べます。

    NameValue
    LANGUAGE GitHub Actions のメッセージを英語にする場合:en を入力します。
    TIMEZONE 日本以外のタイムゾーンにする場合:America/New_York のように入力します。

    「New repository variable」を開く

  4. 4Realms にログインする

    トークンを登録すると、自動的にログインの準備が始まり、3 分ほどで入力するコードが下に表示されます。このコードで Microsoft にサインインすると、少し経ってサイトの構築が始まります。

    ログイン後、Microsoft の画面に「Minecraft for Nintendo Switch」と表示されますが、正常です。

  5. 5仲間にリンクを送る

    サイトを開いて Microsoft でログインします。あなたが管理者です。
    下のアドレスを Realm のメンバーに送ります(サイトの管理者メニュー(右の盾のアイコン)のサイトのURLをコピーからもコピーできます)。

    メンバーは、リンクを開いて、マイクラで使っている Microsoft アカウントでログインするだけです。

    サイトを開く

トラブルシューティング

手順 4 にコードが出てこない
  • 手順 1 の欄に、自分が作ったリポジトリのリンクが入っているか確かめます。
  • 手順 3 のボタンをもう一度開き、Repository secrets に CLOUDFLARE_API_TOKEN があるか確かめます(つづりが一字でも違うと動きません。Variables や Environment secrets ではありません)。
  • リポジトリを作ってから 45 分以上たっている場合は、さらに最大 10 分かかります。
コードが出る前に「ログインできませんでした」と出た

トークンで、Blockmap に必要な操作ができません(作るときに設定が変わった、または途中までしかコピーできていない、など)。

  1. 手順 2 のボタンから、画面の内容を変えずにトークンを作り直します。
  2. 手順 3 のボタンを開き、CLOUDFLARE_API_TOKEN の横の鉛筆マークを押して、新しいトークンを貼り直します。
  3. 20 分ほどのうちに自動でログインがやり直され、手順 4 にコードが出ます。
コードを入れた後に「ログインできませんでした」と出た
  • コードの有効期限は 15 分です。過ぎた場合は、20 分ほどのうちに、手順 4 に自動で新しいコードが出ます。
  • Realm のオーナーの Microsoft アカウントでログインします。
「地図を作れませんでした」と出た
  • 「記録を見る」を開き、赤いメッセージを探します。メッセージごとの意味と直し方は、説明書の表にあります。
  • 赤いメッセージに Cloudflare のこと(アカウント・鍵・公開先のアドレス・公開)が出ている場合は、トークンに必要な権限が足りません。上の「コードが出る前に「ログインできませんでした」と出た」と同じ手順でトークンを作り直して貼り直し、次の地図の更新(1 時間以内)を待ちます。
  • Realm を 2 つ以上持っている場合は、手順 4 で選びます。あとから変えるときは、Variables に REALM_NAME(Realm の名前)を追加して、地図を更新します。
Microsoft の画面に「Minecraft for Nintendo Switch」と出た
  • 正常です。Blockmap は、Switch 版のマイクラと同じ方法で Realms にログインします(理由)。
仲間がサイトに入れない
  • 入れるのは Realm のメンバーだけです。マイクラで使っている Microsoft アカウントでログインしてもらいます。
このページの表示が変わらない
  • ページを再読み込みします。進み具合は、GitHub の Map site でも見られます。
