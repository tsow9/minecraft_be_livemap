Blockmap かんたん設定

Realm の地図サイトを 5 つの手順で立てます。このページはパスワードやトークンを求めず、どこにも送信しません。チェックはこのブラウザにだけ保存されます。

必要なもの:Realm のオーナーの Microsoft アカウント、GitHub アカウント、Cloudflare アカウント(どれも無料)。

  1. 1リポジトリを作る

    1. 下のボタンを開き、Public のまま、Include all branches にはチェックを入れずに作成します。
    なぜ Public? 大丈夫?

    自動更新は GitHub Actions で動きます。Actions を無制限に無料で使えるのは公開リポジトリだけです(非公開は月 2,000 分まで。Blockmap は月 4,000 分ほど使います)。

    公開されるのは、プログラムと暗号化したデータだけです。ゲーマータグや座標は表に出ず、サイトに入れるのは Realm のメンバーだけです。鍵やログイン情報は公開されません。

    GitHub でリポジトリを作る

  2. 2Cloudflare のトークンを作る

    1. 下のボタンを開きます。権限は入力済みです(Workers Scripts: Edit、D1: Edit、Account Settings: Read。足りなければ追加してください)。作成して、表示されたトークンを控えます(一度しか表示されません)。

      トークンを作る

    サイトのアドレスを自分で決める(任意)

    サイトは blockmap.<サブドメイン>.workers.dev になります。Workers & Pages でサブドメインを決めていなければ、GitHub のユーザー名から自動で決まります。自分で決める場合は、手順 5 の前に決めて、ここにも入れてください。

    Workers & Pages を開く

  3. 3Secrets と Variables を登録する

    次の 2 つを Secret として登録します(Name と値を入れて Add secret)。

    「New repository secret」を開く

    REALMS_CACHE_KEY
    CLOUDFLARE_API_TOKEN 手順 2 のトークン

    ランダムな文字列は、このブラウザで今作ったもので、どこにも保存されません。ページを読み直すと作り直されるので、表示中のものを登録してください。覚えておく必要はありません。

    必要なら、次を Variable として登録します(Variables タブ。どれも任意です)。

    「New repository variable」を開く

    LANGUAGE (実行時のメッセージの言語。省略時は英語)
    TIMEZONE (地図の日付。省略時は Asia/Tokyo)
    REALM_NAME Realm を 2 つ以上持っている場合だけ、使う Realm の名前
    CLOUDFLARE_ACCOUNT_ID Cloudflare のアカウントを複数持っている場合だけ(Secret として登録)

  4. 4Realms にログインする

    1. 下のワークフローを開きます(初回は Actions タブでワークフローを有効にします)。
    2. 「Run workflow」→ What to do で Sign in to Realms を選び → Run workflow。
    3. 実行中の login を開き、表示されたコードを microsoft.com/link に入れて、Realm のオーナーのアカウントでログインします。

    「Map site」を開く

  5. 5地図を作る

    1. 同じ画面で「Run workflow」→ Update map を実行します。数分かかります。
    2. 終わったら、サイトを開いて Microsoft でログインします。あなたが管理者です。

    サイトを開く

    あとは、住所を Realm のメンバーに送るだけです(管理者メニュー → サイトのURLをコピー)。
