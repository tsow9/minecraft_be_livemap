Blockmap セットアップ

Realm のメンバーだけが見られる地図サイトを作ります。できたサイトのリンクを仲間に送れば、みんながブラウザで地図を見られます。

所要時間は 15 分ほどです。このページでパスワードやトークンを入力することはありません。入力した内容はどこにも送信しません。どこまで進んだかだけを、匿名で数えています(詳しく)。

必要なもの(すべて無料):Realm のオーナーの Microsoft アカウント、GitHub アカウント、Cloudflare アカウント

  1. 1リポジトリを作る

    下のボタンを開いて、リポジトリを作ります。公開範囲は Public のままにします。Include all branches にはチェックを入れません。

    自動更新は GitHub Actions で動きます。Actions を無制限に無料で使えるのは、公開リポジトリだけです。非公開は月 2,000 分までで、Blockmap は月 4,000 分ほど使います。

    公開されるのは、プログラムと暗号化したデータだけです。ゲーマータグや座標は表に出ず、サイトに入れるのは Realm のメンバーだけです。

    GitHub でリポジトリを作る

  2. 2Cloudflare のトークンを作る

    下のボタンを開き、内容を確認して Continue to summary → Create Token を押します。表示されたトークンをコピーします。トークンは一度しか表示されません。

    トークンを作る

    次のようになっていれば大丈夫です。足りないものは追加します。

    • Permissions
      • Account · Workers Scripts · Edit
      • Account · D1 · Edit
      • Account · Account Settings · Read
    • Account Resources: Include · All accounts
    • TTL: Token expiration · No expiration
    • Client IP Address Filtering: 空のまま

  3. 3トークンをリポジトリに登録する

    下のボタンを開き、Name と Secret を入れて Add secret を押します。

    「New repository secret」を開く

    NameSecret
    CLOUDFLARE_API_TOKEN 手順 2 のトークン
    必要な場合だけ
    REALM_NAMEVariables Realm を 2 つ以上持っている場合:Realm の名前を入力します(例:「〇〇のRealm」)。
    CLOUDFLARE_ACCOUNT_IDSecrets Cloudflare のアカウントを 2 つ以上持っている場合:使うアカウントの ID を入力します。
    LANGUAGEVariables GitHub Actions のメッセージを英語にする場合:en を入力します。
    TIMEZONEVariables 日本以外のタイムゾーンにする場合:America/New_York のように入力します。

  4. 4Realms にログインする

    1. 下のボタンを開きます。初回は I understand my workflows, go ahead and enable them を押します。
    2. 右の Run workflow を押し、What to do を Sign in to Realms にして、緑の Run workflow を押します。
    3. このページに戻ります。コードの場所と地図の進み具合が、ここに表示されます。ログインすると、続けて地図が作られます。

    「Map site」を開く

    ログイン後、Microsoft の画面に「Minecraft for Nintendo Switch」と表示されますが、正常です。Realms には公開された入り口がないため、Switch 版マイクラと同じ方法でログインしています。使えるのは Xbox Live と Realms だけで、メール・ファイル・支払いには届きません。パスワードも扱いません。

  5. 5仲間にリンクを送る

    サイトを開いて Microsoft でログインします。あなたが管理者です。右の管理者メニュー(盾のアイコン)でサイトのURLをコピーを押し、リンクを Realm のメンバーに送ります。

    メンバーは、リンクを開いて、マイクラで使っている Microsoft アカウントでログインするだけです。

    サイトを開く
