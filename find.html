[ 地図を探す ]

地図のアドレスを忘れたときは、地図サイトを作った人の GitHub のユーザー名(またはリポジトリのリンク)を入れてください。その人の Chizuya の地図サイトを探します。

リポジトリ地図のアドレス操作

入れた名前は GitHub に問い合わせるだけで、どこにも保存しません。アドレスが分かっても、地図を見られるのはその Realm のメンバーだけです。
