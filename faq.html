よくある質問

Q. 料金はかかりますか?

無料です。GitHub と Cloudflare の無料プランの範囲で利用できます。

Q. Java 版でも使えますか?

使えません。マインクラフト統合版の Realm 専用です。

Q. 地図のデータはどこに保存されますか?

ご自身の Cloudflare アカウントに保存されます。作成途中のデータは、暗号化したうえでご自身の GitHub リポジトリに保存されます。開発者のサーバーには保存されません。

Q. Realm のオーナーでなくても使えますか?

使えません。ワールドを取得できるのはオーナーのアカウントだけのため、オーナーご本人による設定が必要です。

Q. 地図サイトを削除するには?

地図サイトとデータを削除するには、次の手順を行ってください。

  1. Cloudflare のダッシュボードで「Workers & Pages」を開き、地図サイト(アドレスの先頭と同じ名前)を選択します。「Settings」の最下部から削除してください。
  2. Cloudflare のダッシュボードで「D1」を開き、「(サイト名)-share」という名前のデータベースを削除してください。
  3. GitHub でリポジトリを開き、「Settings」の最下部にある「Delete this repository」から削除してください。自動更新が停止し、エラー通知のメールも届かなくなります。
  4. 安全のため、不要になった Cloudflare の API トークン(「My Profile」→「API Tokens」)と、GitHub アプリ「Chizuya Connect」(「Settings」→「Applications」)も削除してください。

FAQ

Q. Does it cost anything?

No. It is free and runs within the free plans of GitHub and Cloudflare.

Q. Does it work with Java Edition?

No. It supports Minecraft Bedrock Edition Realms only.

Q. Where is the map data stored?

In your own Cloudflare account. Data in progress is encrypted and stored in your own GitHub repository. Nothing is stored on the developer’s servers.

Q. Can I use it if I am not the Realm owner?

No. Only the owner’s account can download the world, so the owner must set it up.

Q. How do I delete a map site?

To delete a map site and its data, follow these steps.

  1. In the Cloudflare dashboard, open “Workers & Pages” and select the map site (named like the start of its address). Delete it from the bottom of “Settings”.
  2. In the Cloudflare dashboard, open “D1” and delete the database named “(site name)-share”.
  3. On GitHub, open the repository and delete it with “Delete this repository” at the bottom of “Settings”. Automatic updates stop, and error notification emails will no longer be sent.
  4. For safety, also delete the Cloudflare API token you no longer need (“My Profile” → “API Tokens”) and the GitHub app “Chizuya Connect” (“Settings” → “Applications”).
