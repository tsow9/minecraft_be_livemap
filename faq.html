よくある質問

Q. 料金はかかりますか?

かかりません。GitHub と Cloudflare の無料プランの範囲で動きます。

Q. Java 版でも使えますか?

使えません。統合版の Realm 専用です。

Q. 地図のデータはどこに保存されますか?

ご自身の Cloudflare アカウントです。作る途中のデータは、暗号化してご自身の GitHub に置かれます。開発者のサーバーには保存されません。

Q. Realm のオーナーでなくても使えますか?

使えません。ワールドを取り出せるのはオーナーだけのため、オーナーのアカウントが必要です。

Q. 地図サイトを消すには?

次の3つを消すと、地図サイトとデータがすべてなくなります。

  1. Cloudflare のダッシュボードの「Workers & Pages」で、地図サイト(住所の最初の部分と同じ名前)を開き、「Settings」のいちばん下から削除します。
  2. 同じく Cloudflare の「D1」で、「(サイト名)-share」というデータベースを削除します。
  3. GitHub でリポジトリを開き、「Settings」のいちばん下の「Delete this repository」で削除します。自動の更新も止まり、失敗のメールも届かなくなります。

使わなくなった Cloudflare のトークン(My Profile の「API Tokens」)と、GitHub のアプリ「Chizuya Connect」(Settings の「Applications」)も消してかまいません。

FAQ

Q. Does it cost anything?

No. It runs within GitHub’s and Cloudflare’s free plans.

Q. Does it work with Java Edition?

No. It is for Bedrock Edition Realms only.

Q. Where is the map kept?

In your own Cloudflare account. While it is being made, the data sits encrypted in your own GitHub. Nothing is kept on the developer’s servers.

Q. Can I use it if I don’t own the Realm?

No. Only the owner can download the world, so the owner’s account is needed.

Q. How do I delete a map site?

Delete these three, and the map site and all its data are gone.

  1. In Cloudflare’s dashboard, under “Workers & Pages”, open the map site (named like the first part of its address) and delete it at the bottom of “Settings”.
  2. Also in Cloudflare, under “D1”, delete the database named “(site name)-share”.
  3. On GitHub, open the repository and delete it with “Delete this repository” at the bottom of “Settings”. Its automatic updates stop too, and no more failure emails arrive.

You can also delete the Cloudflare token you no longer use (My Profile → “API Tokens”) and the GitHub app “Chizuya Connect” (Settings → “Applications”).
